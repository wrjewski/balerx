# Event fixtures are synthetic

`endpoint-process-started.json` and `github-repository-pushed.json` are hand-written examples for SecurityEvent v1.

- Identifiers are obvious placeholders (`11111111-1111-4111-8111-111111111111`, `fixture-user`, `example/repository`).
- The executable hash is 64 `a` characters, not a hash of a real binary.
- No customer, tenant, host, or credential from a running system is included.
