# Demo home

This directory is a fake home for the README recording. It is not a credential and it is not a scan of a real machine.

`home/.cursor/mcp.json` is a Cursor config with a plain HTTP MCP URL and no auth. `home/.claude.json` is a Claude Code config that starts an unpinned `npx` package. Both homes include a Balerx hook command so the recording shows those MCP findings. The recording copies this tree to `/home/demo` and runs `balerx` with that home directory. No tokens are in these files.
